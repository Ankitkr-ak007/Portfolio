# Deployment & Production Infrastructure

## 1. Supported Deployment Targets

The portfolio is structured as a high-performance Single Page Application (SPA) compatible with modern edge-network static hosting providers:
- **Vercel** (Primary Production Target)
- **Netlify**
- **Cloudflare Pages**
- **GitHub Pages**

---

## 2. Vercel Configuration (`vercel.json`)

```json
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ],
  "headers": [
    {
      "source": "/assets/(.*)",
      "headers": [
        {
          "key": "Cache-Control",
          "value": "public, max-age=31536000, immutable"
        }
      ]
    }
  ]
}
```

### Key Configurations:
- **SPA Rewrites**: All incoming route requests fallback to `/index.html`, eliminating 404 errors during deep-linking or page refreshes.
- **Immutable Asset Caching**: Static bundles in `/assets/` include cryptographic content hashes generated by Vite, cached for 1 full year (`max-age=31536000, immutable`).

## 3. Production Build Pipeline

Run locally or via CI:
```bash
npm run build
```

### Execution Steps:
1. `tsc -b`: Strict project-wide TypeScript type compilation.
2. `vite build`: Tree-shaking, CSS minification, and chunk splitting.

### Output Chunks Breakdown:
- `dist/assets/vendor-three-*.js`: Three.js, R3F, and Drei modules (~237 kB gzip).
- `dist/assets/vendor-motion-*.js`: Motion physics and layout engine (~41 kB gzip).
- `dist/assets/vendor-icons-*.js`: Lucide icons & brand vectors (~8 kB gzip).
- `dist/assets/index-*.js`: Core portfolio components & data layer (~108 kB gzip).
- `dist/assets/index-*.css`: Tailwind v4 utility styles & custom keyframes (~10.7 kB gzip).

## 4. Continuous Integration (GitHub Actions)

Located at [`.github/workflows/ci.yml`](file:///C:/Users/Ankit%20Kumar/Portfolio/.github/workflows/ci.yml):

```yaml
name: CI Pipeline

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  quality-gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: 'npm'
      - run: npm ci
      - run: npm run lint
      - run: npm run typecheck
      - run: npm run test:unit
      - run: npm run build

  e2e-testing:
    needs: quality-gate
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: 'npm'
      - run: npm ci
      - run: npm run build
      - run: npx playwright install --with-deps chromium
      - run: npx playwright test --project=desktop-1440x900
```
